# 🐾 Buddy Run

Buddy Run เป็นเว็บไซต์สำหรับจัดกิจกรรม Virtual Run สำหรับคนรักสัตว์ โดยผู้ใช้งานสามารถสมัครกิจกรรม ส่งผลการวิ่ง แจ้งชำระเงิน และติดตามสถานะได้ผ่านเว็บไซต์

---

## 🎯 Project Goal

สร้างระบบ Virtual Run ที่ใช้งานง่าย รองรับทั้ง Desktop และ Mobile พร้อมระบบจัดการสำหรับผู้ดูแล

---
